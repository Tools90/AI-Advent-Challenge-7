# AI Advent Challenge — День 7

Agent Console: чат с агентом, который вызывает инструменты через tool calling и сохраняет контекст между перезапусками.

## Как работает агент

1. Пользователь отправляет сообщение.
2. Агент отправляет историю + схемы инструментов в DeepSeek.
3. Если модель вернула `tool_calls`, агент:
   - выполняет каждый инструмент;
   - добавляет в историю assistant-сообщение с `tool_calls`;
   - добавляет tool-сообщения с результатами;
   - снова вызывает модель.
4. Когда `tool_calls` больше нет — возвращает финальный ответ.
5. Защита от зацикливания: максимум 6 шагов модели.

## Инструменты

| Инструмент | Аргументы | Что делает |
|---|---|---|
| `get_current_time` | `timezone` (IANA, опционально) | Текущие дата/время, по умолчанию UTC |
| `calculate` | `expression` | Арифметика: `+ - * /`, скобки, десятичные дроби |
| `convert_currency` | `amount`, `from`, `to` | Конвертация RUB / USD / EUR / CNY по фиксированному курсу |

Фиксированные курсы (зашиты в коде): 1 USD = 92.5 RUB, 1 EUR = 100 RUB, 1 CNY = 12.8 RUB.

## Проверочные запросы

- Без инструментов: `Что такое HTTP?`
- Один инструмент: `Сколько будет 17 * 23?`
- Два инструмента: `Сколько рублей в 15% от 200 долларов?`
  - `calculate("0.15*200")` → 30
  - `convert_currency(30, USD, RUB)` → 2775

## Запуск

1. Вставьте ключ DeepSeek в `api_key.txt`:

   ```
   sk-...
   ```

2. Запустите:

   ```powershell
   go run .
   ```

3. Откройте http://localhost:8086

## Настройки (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DEEPSEEK_API_KEY_FILE` | `api_key.txt` | Файл с ключом |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | Базовый URL API |
| `DEEPSEEK_MODEL` | `deepseek-flash` | Модель |
| `PORT` | `8086` | Порт сервера |

Модель работает с `thinking: disabled` и `temperature: 0`, чтобы tool calling был предсказуемым.

## Интерфейс

- Слева — каталог инструментов со схемами аргументов.
- Кнопки проверочных запросов.
- Справа — чат: сообщение пользователя, карточки `tool_calls` с аргументами и результатами, финальный ответ.
- Для каждого вызова LLM видны полный запрос (модель, сообщения, tools, параметры) и ответ (content/tool_calls, usage, finish_reason). Запрос и ответ можно развернуть на весь экран.
- Вся работа агента (LLM-вызовы и tool_calls) свёрнута в блок «Работа агента»; по умолчанию он закрыт, финальный ответ виден сразу.
- У каждого хода — количество шагов модели, токены и время.
- «Сбросить контекст» очищает историю.

## Хранение и контекст

- `data/chat.json` хранит полный контекст агента: `messages` с `user`, `assistant` + `tool_calls`, `tool` с результатами и финальными ответами, а также `turns` для UI.
- При старте история загружается и передаётся агенту как есть — диалог продолжается после перезапуска.
- Системный промпт не сохраняется и добавляется заново при каждом запуске.
- Старый формат без `messages` мигрируется из `turns` (только user + final assistant).
- «Сбросить контекст» очищает и `messages`, и `turns`.
- `data/`, `.env`, `api_key.txt` — в `.gitignore`.
